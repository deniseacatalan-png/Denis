# Denis


## Supabase admin

1. Copiá `.env.example` a `.env` y completá `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`.
2. Corré las migraciones y seed en Supabase SQL Editor (`supabase/migrations/*` y `supabase/seed.sql`).
3. Abrí `/admin` para entrar al administrador con magic link por email.
4. En Supabase Authentication, creá/invitá el usuario administrador (email) para poder iniciar sesión.
